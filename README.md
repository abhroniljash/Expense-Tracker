# 💰 Personal Finance Tracker

A simple **Python-based Personal Finance Tracker** that helps users manage their income and expenses through a command-line interface.

## ✨ Features

* ➕ Add Income
* 💸 Add Expenses
* 📋 View All Records
* 📊 Monthly Summary
* 🏷️ Category-wise Summary
* 📅 Store transaction dates
* 📝 Add notes to expenses
* 💾 Save records using file handling
* 🛡️ Basic input validation

## 🗂️ Expense Categories

* 🍔 Food
* ✈️ Travel
* 🏠 Rent
* 🛍️ Shopping
* 📦 Other

## 🛠️ Technologies Used

* Python
* File Handling
* Exception Handling
* Loops
* Conditional Statements
* String Manipulation

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/Personal-Finance-Tracker.git
```

### 2. Open the Project Folder

```bash
cd Personal-Finance-Tracker
```

### 3. Run the Program

```bash
python app.py
```
